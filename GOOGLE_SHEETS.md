# Подключение Google Таблицы

Сайт умеет подгружать расписание из публичной Google Таблицы. Учителя заполняют таблицу — изменения автоматически появляются на сайте.

## 🚀 Быстрый старт (для админа)

### Шаг 1: Скачайте готовый шаблон

Скачайте файл [`schedule-template.xlsx`](schedule-template.xlsx) — он уже настроен:
- Готовая шапка с правильными колонками
- 5 строк-примеров
- Выпадающие списки для групп (35 групп колледжа)
- Проверка пар (1-7) и формата даты
- Лист с инструкцией внутри
- Расписание звонков для справки

> Прямая ссылка для скачивания: <https://github.com/MPEworld/Ipek-/raw/main/schedule-template.xlsx>

### Шаг 2: Загрузите в Google Диск

1. Откройте <https://drive.google.com>
2. **Создать** → **Загрузить файл** → выберите `schedule-template.xlsx`
3. Найдите файл в списке → клик правой кнопкой → **Открыть с помощью** → **Google Таблицы**
4. Файл автоматически конвертируется

### Шаг 3: Опубликуйте таблицу как CSV

В Google Таблицах:
1. **Файл** → **Опубликовать в интернете**
2. Слева выберите: **Весь документ** (или конкретный лист «Расписание»)
3. Справа: **CSV (значения, разделённые запятыми)**
4. Поставьте галку **«Автоматически публиковать после внесения изменений»**
5. Нажмите **Опубликовать** → подтвердите
6. Скопируйте появившуюся ссылку — она будет вида `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?output=csv`

### Шаг 4: Вставьте ссылку на сайте

1. На сайте <https://mpeworld.github.io/Ipek-/> откройте шестерёнку (⚙️) справа сверху
2. Прокрутите до блока **«Google Таблица с расписанием»**
3. Вставьте скопированную ссылку в поле
4. Нажмите **Применить**

Готово. На странице расписания появится зелёная плашка «Данные из Google Таблицы».

### Шаг 5: Дайте редактирование коллегам

В Google Таблицах:
1. Кнопка **Поделиться** справа сверху
2. Введите email коллеги или включите **Доступ по ссылке: Редактор**
3. Скопируйте ссылку доступа и отправьте коллегам

## 👨‍🏫 Для учителей (заполняющих таблицу)

1. Откройте присланную ссылку на Google Таблицу
2. Перейдите на лист **«Расписание»**
3. Добавьте строку: дата, группа, пара, время, предмет, преподаватель, кабинет
   - Группа выбирается из выпадающего списка
   - Пара — число от 1 до 7
   - Дата в формате `ГГГГ-ММ-ДД`, например `2026-09-01`
4. Сохраните (Google Таблицы сохраняют автоматически)
5. На сайте обновление появится в течение 5 минут

### Колонки

| Колонка | Обязательно | Пример | Описание |
|---------|-------------|--------|----------|
| Дата | да | `2026-09-01` | Формат `ГГГГ-ММ-ДД` |
| Группа | да | `Э-25-1` | Из выпадающего списка |
| Пара | да | `1` | Число 1-7 |
| Начало | нет | `8:30` | Время начала |
| Конец | нет | `10:00` | Время окончания |
| Предмет | да | `Математика` | Название предмета |
| Преподаватель | нет | `Соковикова` | Фамилия (или через `/`) |
| Кабинет | нет | `206` | Номер кабинета или место |
| Заметка | нет | `дистанционно` | `дистанционно`, `экзамен`, `практика` |

### Если нет вашей группы

Откройте лист **«Группы»** в таблице и добавьте новую строку с названием. После этого в выпадающем списке появится новая группа.

## 🔧 Как это работает технически

- **Перекрытие**: данные из таблицы перекрывают расписание с `pilot-ipek.ru` для тех же дат и групп
- **Дополнение**: если в таблице есть дата, которой нет в основном расписании, она появится отдельным днём
- **Кэш**: сайт перепроверяет таблицу каждые 5 минут
- **Безопасность**: ссылка хранится только в браузере конкретного пользователя (localStorage). Если хотите общую ссылку для всех — вставьте URL в код (см. `app.js`, константа `savedSheetUrl`)

## 🧹 Сбросить и вернуться к pilot-ipek.ru

В настройках → блок «Google Таблица» → кнопка **Сбросить**.
