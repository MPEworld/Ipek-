# ИПЭК расписание

Статический сайт расписания Ижевского промышленно-экономического колледжа с адаптивным интерфейсом, темами оформления, добровольным профилем студента, поиском, новостями, карточками преподавателей и контактами.

## Обновление расписания

Данные лежат в `data.js`. Чтобы подтянуть актуальные таблицы с официального сайта, запустите:

```bash
node tools/update-schedule.js
```

Скрипт берёт `https://www.pilot-ipek.ru/schedule.html`, находит страницы дней и переписывает `data.js`. Если официальный сайт отдаёт защитную страницу Access Denied, скрипт остановится и не испортит текущие данные.

## Локальный просмотр

Сайт можно открыть как обычный файл `index.html` или поднять простой сервер:

```bash
python3 -m http.server 8000
```

## Публикация на GitHub Pages

1. Добавьте GitHub-репозиторий как `origin`, если его ещё нет.
2. Отправьте ветку `main` на GitHub.
3. В настройках репозитория откройте `Settings` → `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`, ветку `main`, папку `/root`.

После этого сайт будет доступен по адресу вида:

```text
https://<ваш-логин>.github.io/<имя-репозитория>/
```

Каркас Telegram/Max-бота лежит в `bots/schedule-bot`.
