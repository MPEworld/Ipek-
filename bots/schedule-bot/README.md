# Бот расписания ИПЭК

Минимальный сервер без внешних зависимостей. Он читает `../../data.js`, поэтому сайт и бот работают от одного источника расписания.

## Запуск

```bash
cp .env.example .env
npm start
```

Переменные:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather.
- `MAX_BOT_TOKEN` и `MAX_API_URL` — адрес и токен отправки сообщений Max. API Max нужно уточнить по актуальной документации сервиса.
- `SITE_URL` — ссылка на опубликованный сайт, чтобы бот мог отправлять кнопку/ссылку.

## Webhook

- `POST /telegram` — Telegram webhook.
- `POST /max` — Max webhook-адаптер.
- `GET /health` — проверка сервера.

Команды:

- `/today В-25-1` — расписание группы на ближайший день.
- `/teacher Созонова` — пары преподавателя.
- `/week В-25-1` — пример недели по статистике загруженных дней.
- `/events` — ссылка на новости и мероприятия.
- `/help` — подсказка.
